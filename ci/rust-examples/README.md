# DNA Rust examples — compile harness

This crate does not contain hand-written source. `src/lib.rs` is generated by
`ci/extract_rust_examples.py`, which reads `languages/RUST.md`, pulls out
every fenced code block whose info string is exactly ```` ```rust ````, and
concatenates them in document order into a single flat module. It exists so
that `languages/RUST.md`'s own advice — including its axum handlers, its
`utoipa` OpenAPI wiring, its keyset-pagination `sqlx` example, and its
`time`-based timestamp formatting — is guaranteed to actually compile and run
rather than merely look plausible. This is the concrete enforcement mechanism
for PLID-42.04 *Runnable & Verified Examples*: a norm set that mandates
runnable examples has to hold its own examples to that bar.

To regenerate and verify locally, run from the repository root:

```text
python3 ci/extract_rust_examples.py
cargo check --manifest-path ci/rust-examples/Cargo.toml
cargo test  --manifest-path ci/rust-examples/Cargo.toml
```

The first command rewrites `src/lib.rs` from the current state of
`languages/RUST.md`; the next two type-check the result and run any
`#[test]` functions embedded in the guide (for example, the round-trip test
proving that whole-second timestamps still serialise with three subsecond
digits). If you edit a Rust snippet in `RUST.md`, re-run all three before
committing — do not hand-edit `src/lib.rs`, since it is overwritten on every
regeneration. If a snippet needs a dependency the crate doesn't have yet, add
it to `Cargo.toml` here rather than changing what the guide shows.
